# 台股題材雷達

<https://kresselock.github.io/theme-tracker-site/>

每天彙整台灣財經媒體的台股新聞，統計「媒體最近在炒哪些題材、提到哪些個股」，
再用實際市場數據檢查這些題材是**真的有需求**，還是**只有話題熱度**。

## 更新時間

- 週一～週五 **08:00**（台北時間）更新，開盤前可看
- 每天的報告會存檔在 [`reports/`](reports/)，檔名是日期（例：`reports/2026-09-30.html`）

### 實質需求 or 炒作？

每個熱門題材會對照相關個股的**月營收年增、法人買賣超、融資增減、股價漲幅**（ETF 另看受益權單位增減與除息），給出下列其中一種判斷：

- **實質需求**：營收有成長、報導有具體數據
- **部分實質**：部分個股有數據支撐，部分沒有
- **炒作風險高**：多為模糊用語、來源集中、股價大漲但營收沒跟上、融資快速增加
- **證據不足**：資料太少，還無法判斷

### 數據怎麼看

- **法人買賣超不含自營商避險**：避險多半是權證或 ETF 造市、申購買回的對沖，不代表看多或看空
- **ETF** 沒有營收，改看**受益權單位增減**（正值＝有人申購、負值＝有人買回）和**折溢價**，比法人張數更接近實際資金進出
- **除息**：30 天內要除息的會標出日期；除息前融資或申購增加，常是為了參與配息
- **20 日含息**：區間內已除息的，漲跌會把配息加回去，避免把除息缺口誤當成下跌
