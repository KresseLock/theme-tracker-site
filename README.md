# 台股題材雷達

<https://kresselock.github.io/theme-tracker-site/>

每天彙整台灣財經媒體的台股新聞，統計「媒體最近在炒哪些題材、提到哪些個股」，
再用實際市場數據檢查這些題材是**真的有需求**，還是**只有話題熱度**。

## 更新時間

- 週一～週五 **07:00**（台北時間）更新，開盤前可看
- 每天的報告會存檔在 [`reports/`](reports/)，檔名是日期（例：`reports/2026-09-30.html`）

### 題材階段

| 標示 | 意思 |
|---|---|
| 🆕 新題材 | 最近才出現 |
| 🔺 升溫 | 報導量增加中 |
| 🔥 高峰 | 報導量在高點 |
| ➖ 持平 | 變化不大 |
| 🔻 退燒 | 報導量下滑 |

### 實質需求 or 炒作？

每個熱門題材會對照相關個股的**月營收年增、三大法人買賣超、融資增減、股價漲幅**，給出下列其中一種判斷：

- **實質需求**：營收有成長、報導有具體數據
- **部分實質**：部分個股有數據支撐，部分沒有
- **炒作風險高**：多為模糊用語、來源集中、股價大漲但營收沒跟上、融資快速增加
- **證據不足**：資料太少，還無法判斷

## 資料來源

- 市場數據：[FinMind](https://finmindtrade.com/)
